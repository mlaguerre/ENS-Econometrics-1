About the course

The course equips you with tools to quantitatively explore relevant social science questions, with a focus on intuition, using both real and simulated data.

A typical lecture:

  • introduce concepts and intuition,
  • exercise and application in R,
  • a bit of maths.

Software and data

Applications are in R. Please install R and RStudio before the first session, then run in R:

install.packages(c("wooldridge", "tidyverse", "data.table"))

Most examples use datasets from the wooldridge package (e.g. data("wage1")). Any other dataset will be posted on this website.
