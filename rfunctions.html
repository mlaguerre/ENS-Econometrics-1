stepAIC() MASS

Stepwise model selection: starting from a fitted model, stepAIC() adds and/or removes covariates one at a time, as long as this lowers the Akaike Information Criterion (AIC).

How to use it

library(MASS)
stepAIC(object, scope, direction = c("both", "backward", "forward"), k = 2, trace = 1)
objectThe starting model, e.g. a fit from lm().
scopeThe range of models to search, e.g. list(lower = ~ 1, upper = ~ x1 + x2 + x3). Required for forward selection; for backward elimination the starting model is used as the upper model.
direction"backward", "forward" or "both" (default).
kPenalty per parameter: k = 2 gives the AIC, k = log(n) gives the BIC.
tracePrint every step (1) or not (0).

It returns the selected model (a fitted lm object, to be used with summary(), predict(), …). The sequence of steps is stored in $anova.

What it computes

For a model with \(p\) covariates, i.e. \(p + 1\) coefficients with the intercept, and maximized likelihood \(\hat{L}\), the AIC is

$$\text{AIC} = -2 \log \hat{L} + 2(p+1).$$

The first term rewards goodness of fit, the second penalizes complexity: lower is better. For a linear regression with Gaussian errors, stepAIC() uses, up to a constant,

$$\text{AIC} = n \log\left(\frac{\text{RSS}}{n}\right) + 2(p+1), \qquad \text{RSS} = \sum_{i=1}^n \hat{\varepsilon}_i^2 .$$

At each step, it computes the AIC of every model obtained by adding or dropping a single covariate, moves to the model with the lowest AIC, and stops when no such move lowers the AIC.

Backward and forward selection

  • Backward elimination (direction = "backward"): start from the full model with all candidate covariates. At each step, remove the covariate whose removal lowers the AIC the most. Stop when removing any covariate would increase the AIC.
  • Forward selection (direction = "forward"): start from the intercept-only model. At each step, add the candidate covariate that lowers the AIC the most. Stop when adding any covariate would increase the AIC.
  • Both (direction = "both", the default): at each step, consider both adding and removing a covariate.

These are greedy searches. With \(p\) candidate covariates there are \(2^p - 1\) possible models with at least one covariate; stepwise methods fit at most about \(p^2/2\) of them. This makes them fast, but they are not guaranteed to find the model with the lowest AIC, and backward and forward selection can end at different models, as in the example below.

Example

Log hourly wage in the wage1 data, with \(p = 12\) candidate covariates (13 coefficients in the full model):

library(MASS)
library(wooldridge)
data("wage1")

# Full model with all candidate covariates
full = lm(lwage ~ educ + exper + expersq + tenure + female + married + nonwhite +
            numdep + smsa + northcen + south + west, data = wage1)

# Backward elimination
back = stepAIC(full, direction = "backward", trace = FALSE)
back$anova

# Forward selection, from the intercept-only model
null = lm(lwage ~ 1, data = wage1)
fwd  = stepAIC(null, scope = list(lower = ~ 1, upper = formula(full)),
               direction = "forward", trace = FALSE)
fwd$anova

Backward elimination drops nonwhite and west and keeps 10 covariates. Forward selection stops at 9 covariates: it includes west but neither northcen nor south. The two searches end at different models, and the forward model has the lower AIC (−971.3 vs −970.3).

Good to know

  • The values printed by stepAIC() differ from those of AIC() by a constant. This does not change the comparison between models.
  • The p-values and confidence intervals reported by summary() on the selected model ignore the selection step, so they are too optimistic.
  • The AIC is a criterion for prediction: a selected covariate is not necessarily a causal determinant of the outcome.
  • A factor is added or removed as a whole, with all its dummies at once.
